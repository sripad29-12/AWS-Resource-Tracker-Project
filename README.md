Here is the detailed project description

This project is about tracking the resources of the AWS using bash scripting. Here is the step by step procedure for the project.

Step-1:
Connect to an EC2 instance using it's public IPv4 address through ssh.

Step-2:
Check whether the AWS CLI is installed on the instance. If not install the AWS CLI.

Step-3:
Start writing the script after authorization through the AWS credentials.
